# Wordpress-auto

Commercial WordPress auto parts marketplace starter containing:

- `theme/autoparts-premium` — premium responsive WordPress theme.
- `plugin/autoparts-companion` — companion plugin with catalog logic, requests, REST API, CSV import, notifications, wizard and premium feature flags.
- `docs/ARCHITECTURE.md` — product architecture, CPT schema, feature flags and API plan.
- `docs/README.md` — installation and user/developer documentation.

This repository is intentionally split into theme + plugin so store data remains available when the visual theme changes.
